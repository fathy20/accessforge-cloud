# Tables
1. **profiles**: User metadata.
2. **user_roles**: Role assignments.
3. **projects**: Maintenance events (tail_number, station).
4. **modules**: Available tools (task_extractor, etc.).
5. **module_access**: Permissions matrix.
6. **uploads**: File metadata and storage paths.
7. **tasks**: Extracted maintenance data.
8. **jobs**: Async worker queues.
9. **audit_log**: Activity tracking.
