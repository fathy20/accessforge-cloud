# Crew Hours LEON Read-only Scopes

S4 requires only these read-only LEON API-key scopes for the future Crew Hours source-record integration:

- `GRAPHQL_FLIGHT`
- `GRAPHQL_FLIGHT_CREW_SEE`
- `GRAPHQL_CREW_MEMBER`
- `GRAPHQL_JOURNEY_LOG`
- `GRAPHQL_ACFT`
- `GRAPHQL_AIRPORT`

No edit, mutation, API-key-management, or administrative scope is required by S4.
